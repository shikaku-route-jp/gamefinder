## 最初に必要な入力

楽天アフィリエイト本体でGAMEFINDERの利用サイト登録と利用条件を確認した上で発行した、ゲーム1本分の「画像リンク」のHTMLコード。楽天ショップのトップページや、画像のURLだけでは代用できない。パスワードやAPIキーは不要。

資格ルート用のもしものコードは流用しない。楽天アフィリエイト本体は別サービスであり、公式案内に従って利用サイトの登録と規約の確認を行う。登録や利用許可が済んでいるとは仮定しない。

## 登録形式

```js
const GAME_PRODUCT_LINKS = {
  "games1000.jsの正確なtitle": {
    provider: "rakuten",
    mediaUrl: "https://shikaku-route-jp.github.io/gamefinder/",
    html: `ここに、そのメディア用に発行されたHTMLコードをそのまま貼る`
  }
};
```

コードの画像URL・購入先・計測コード・商品名は書き換えない。通常のゲームタイトル・相性の説明とは別に、商品カード全体を「広告 / PR」と表示する。数値価格・在庫・送料の推測表示は追加しない。別プラットフォーム、別エディション、攻略本、サウンドトラック、グッズをゲーム本体と誤って紐づけない。

未登録の作品や対象メディアが異なるコードは商品カードを出さず、既存の診断結果を継続する。同じ商品リンクのコードを同一結果内で二重表示しない。画像のある作品を優遇するランキング変更は行わない。

`GAME_PRODUCT_LINKS` は運営者が確認してコミットする信頼済みの設定。実行時に検索結果、URLパラメーター、ユーザー入力をHTMLとして渡す仕組みではない。基本的な誤設定検知は、許諾や法的適合性を確認する代わりにはならない。

### HTMLチェックで分かること・分からないこと

- すべての購入リンクの実際の `href` が、HTTPSの `hb.afl.rakuten.co.jp` または `hbb.afl.rakuten.co.jp` であることを確認する。別URLのクエリに楽天URLが含まれるだけでは受け付けない。
- 画像の `src` はHTTPSの `thumbnail.image.rakuten.co.jp` と上記の楽天計測ホストだけを受け付ける。もしもや他サイトのリンク・画像が混ざったHTMLは表示しない。
- 静的な画像付きリンクと基本的なレイアウトタグだけを対象とする。スクリプト、イベント属性、追加の画像読み込み属性、未対応のタグ・属性・形式は、HTMLを修正するのではなく商品欄全体を非表示にする。提供元の形式が変わった場合は実物を確認して対応を検討する。
- これは運営者が確認済みの設定を検査する処理であり、不特定の投稿HTMLを安全にするサニタイザーではない。
- 楽天の登録状態、アカウントの所有者、画像の利用許可、商品・機種・版の一致は検証できない。
- 重複抑止は同じHTML文字列に限る。同じ商品に対して異なる計測コードを発行した場合は手動で重複を確認する。

## レイアウト

商品コードはTOP5の各カード内へ挿入する。第1位の大型説明欄には同じコードを重複挿入しない。提供HTMLの画像サイズをCSSで変更しない。提供元の作成機能で128pxや240pxなどスマホで収まる設定を選ぶ。画像リンクにスクリプトは不要。

Nodeテストでは仮HTMLのみを使い、実商品へのアクセスは行わない。テスト成功は実ブラウザでのレイアウト、報酬の計測、楽天側の登録・規約適合を保証しない。自己購入や同一生計者による購入で報酬発生を試すことはしない。
