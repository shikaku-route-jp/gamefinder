同一作品の別名は正規化後に重複排除する一方、複数作品が共有する略称は残す。

## 実装

- jp-search.js：正式英語タイトルと一致する124キー、268の作品別名、
  52シリーズの共通ルール。全角・半角、大小文字、ひらがな・カタカナ、
  空白と句読点の違いを吸収する。
- searchGames()：完全一致、前方一致、部分一致の順で候補を並べる。
  FF1 が FF10 や FF16 に一致するなど、数字の途中での一致を避ける。
- app.js：renderBad() と renderGood() は同じ list() を使用し、
  searchGames(q, realGames()) から同じ候補と順序を受け取る。
  反対側で選んだ作品は候補に残し、ボタンだけを無効にする。
- index.html：games800.js → jp-search.js → app.js の順に読み込む。
- games800.js：変更不要。作品ID、英語タイトル、特徴値を維持する。
  Stellar Blade は検索入力だけでなく診断候補にも復帰する。
  スコア計算式と上位5件の選出処理は変更しない。

```sh
node --check jp-search.js
node --check app.js

```

13テストが成功。1,000件の英語タイトル、登録された全268別名、
52シリーズの各共通別名を検索して該当作品を確認した。
さらに検索インデックスの全1,593種類の検索語で、実際の
renderBad() と renderGood() をDOMハーネス上で実行し、
表示される候補ID・順序・先頭40件を比較した。

追加表示では a に一致する全784件に両欄から到達できることを確認した。
空欄・該当なし・仮データの除外、選択と解除、反対側の選択禁止、
5本の上限、診断候補への復帰と選択済み作品の除外も検証した。

## 対応範囲

日本語の作品別名またはシリーズ別名が付いた作品は317件。
1,000件すべての英語タイトル検索と、登録済みの別名・シリーズ名の
検索を確認した。残る683件について、日本語正式名を網羅した辞書を
作ったわけではない。未登録の日本語名・略称は別名の追加が必要。

タイトルごとの別名を追加する際は、JP_ALIASES のキーを
games800.js が生成する GAMES[].title に完全一致させ、
上記テストで未対応キーや重複を検出する。
