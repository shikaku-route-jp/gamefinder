# 診断結果の商品画像と購入リンク

状態：表示機能の下書き。GAMEFINDER用に発行された実際の商品リンクコードが未提供のため、登録は0件。公開サイトにはまだ反映していない。

`product-links.js` の `GAME_PRODUCT_LINKS` に、正規に取得した商品リンクHTMLを登録すると、その作品がTOP5に入ったときに画像付き購入リンクを表示する。タイトルは `games1000.js` の `title` と完全一致させる。診断データ・作品ID・スコア計算は変更しない。

## 最初に必要な入力

GAMEFINDERのメディアを選択して発行した、ゲーム1本分の「もしも・かんたんリンク」または「楽天・画像リンク」のHTMLコード。楽天ショップのトップページや、画像のURLだけでは代用できない。パスワードやAPIキーは不要。

資格ルート用のコードを流用できるとは扱わない。もしもでは複数メディアごとの登録・提携・広告コードの確認が必要になる。

## 登録形式

```js
const GAME_PRODUCT_LINKS = {
  "games1000.jsの正確なtitle": {
    provider: "moshimo", // または "rakuten"
    mediaUrl: "https://shikaku-route-jp.github.io/gamefinder/",
    html: `ここに、そのメディア用に発行されたHTMLコードをそのまま貼る`
  }
};
```

コードの画像URL・購入先・計測コード・商品名は書き換えない。通常のゲームタイトル・相性の説明とは別に、商品カード全体を「広告 / PR」と表示する。数値価格・在庫・送料の推測表示は追加しない。別プラットフォーム、別エディション、攻略本、サウンドトラック、グッズをゲーム本体と誤って紐づけない。

未登録の作品や対象メディアが異なるコードは商品カードを出さず、既存の診断結果を継続する。同じかんたんリンクのコードを同一結果内で二重実行しない。画像のある作品を優遇するランキング変更は行わない。

`GAME_PRODUCT_LINKS` は運営者が確認してコミットする信頼済みの設定。実行時に検索結果、URLパラメーター、ユーザー入力をHTMLとして渡す仕組みではない。基本的な誤設定検知は、許諾や法的適合性を確認する代わりにはならない。

## レイアウト

商品コードはTOP5の各カード内へ挿入する。第1位の大型説明欄には同じコードを重複挿入しない。提供HTMLの画像サイズをCSSで変更しない。固定幅のコードが必要な場合は、提供元の作成機能で128pxや240pxなどスマホで収まる設定を選ぶ。もしものレスポンシブカードは提供元のスクリプトに描画させる。

## 確認元

- https://affiliate.rakuten.co.jp/guides/link/
- https://affiliate.rakuten.co.jp/guideline/rule/
- https://af.moshimo.com/af/www/help

各提供元の利用条件と、そのメディアでの提携状況を、実際のコードを登録するときに確認する。検索結果・ストア・公式サイトの画像を、許可の根拠なく取得して埋め込む実装は含めない。
